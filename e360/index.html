E360 plug in PC version (Chrome browser)

Download E360 PC

Quick install:

  1. Extract file e360-pc.zip
  2. In Chrome / Manage Extensions / Load unpacked / Select folder e360-pc

Feature:

  • Edit directly in the browser. Customize the window in a simple and easy-to-read way.
  • Runs in the background within an iframe, without opening a new tab.
  • It can run on Android phones with Kiwi Browser.

Install for Iphone:

Download E360 IOS

Quick install:

  • Download the app: Install the Stay - Extensions for Safari app from the App Store.
  • Activate: Go to iPhone Settings > Safari > Extensions > Select Stay and turn it on. Set website access permissions to Allow.
  • Add an Extension: Open the Stay app, tap the "+" button in the upper corner. Here you can:
    • Paste the extension link directly from the Chrome Web Store.
    • Install Userscripts from GreasyFork.
    • Upload internal script/extension files.
Note: When you access the e360 website, remember to switch to the desktop interface (there's a button to click on it in the menu on the interface).
